FreeCAD for HarmonyOS 是社区开发者基于开源三维参数化设计软件 FreeCAD 1.1.2 制作的 HarmonyOS PC（2in1 设备）原生版本，使用 Qt 6 与 OpenGL ES 构建，与上游共享同一套几何内核与工作台代码，不是网页套壳，也不是远程桌面。

【主要功能】

一、参数化三维建模
Part 工作台提供实体布尔运算与基本体；PartDesign 工作台以草图驱动特征建模，支持拉伸、开槽、旋转、放样、扫掠等常用特征；Sketcher 工作台提供完整的二维约束草图，可以用尺寸约束与几何约束把设计意图固定下来。整套模型保留设计历史，随时可以回过头修改早期参数。

二、装配与工程图
Assembly 工作台用于把零件组装成产品：插入零件与子装配、定义装配关节、求解装配位置，并支持装配体的运动仿真与物料清单（BOM）输出。TechDraw 工作台由三维模型自动生成带尺寸与剖视的工程图。

三、曲面与二维绘图
Surface 工作台用于创建与修补曲面。Draft 工作台绘制二维图形、做阵列与变换，并可导出为 DXF、SVG 等工程格式。

四、网格与点云
Mesh 工作台处理三角网格，可导入、修复、简化、检查并做布尔运算，适合三维打印前的模型准备；Points 工作台用于扫描点云文件的导入与处理；Inspection 工作台用于把实测数据与设计模型做尺寸比对。

五、建筑、仿真与加工
BIM 工作台按建筑信息模型的思路组织构件，提供墙体、结构构件、门窗、楼层、空间等对象，适合建筑与室内方案建模，并可与 Draft 协同出图；Fem 工作台提供有限元分析的前后处理；CAM 工作台生成数控加工路径；Spreadsheet 工作台用表格参数驱动模型，适合系列化与标准化设计。

六、脚本与扩展
内置 Python 3.11 控制台，可以执行脚本、录制宏、批量处理模型。熟悉 Python 的用户可以直接调用 FreeCAD 的 API 自动建模或实现自己的参数化流程；应用内提供插件管理器（Addon Manager）入口。

七、AI 辅助
内置第三方开源插件 FreeCAD AI 工作台。在你自行配置好大模型服务之后，可以用对话的方式辅助生成与修改建模脚本。该功能需要你自备第三方模型服务的 API Key，并需要可用的网络连接；应用自身不提供大模型服务，也不会收集你的对话内容。

八、其他工作台
应用内同时提供 Measure（尺寸测量）、Material（材料属性）等工作台，可在同一窗口中直接切换使用。

【支持的文件格式】
工程文档：FCStd、BREP
三维交换：STEP、IGES、STL、OBJ、PLY、AMF、3MF
二维与矢量：DXF、SVG
说明：DWG 与 IFC 的读写依赖额外的第三方转换组件，本版本未预置，因此不支持这两种格式。

【使用说明】
1、本应用适用于 HarmonyOS PC 与 2in1 设备（ARM64 架构）。
2、操作方式沿用桌面版 FreeCAD，请配合鼠标与键盘使用。触摸屏可以完成点按菜单、工具栏等操作，但三维视图的旋转平移、面板与列表滚动在触摸下体验有限，建议使用鼠标。
3、界面默认简体中文，菜单、命令与对话框均已本地化；可在首次启动的设置页或首选项的语言项中切换其他语言。工作台名称与对象名称沿用 FreeCAD 原生的英文命名。
4、首次启动需要解压程序运行时，会占用一定时间与磁盘空间，请耐心等待。
5、应用申请两个权限，且都只在对应功能中使用：网络权限用于插件管理，以及 FreeCAD AI 工作台访问你自行配置的模型服务；读取剪贴板权限仅在你把外部复制的文本（例如 API Key）粘贴到应用内输入框时使用。应用不会在后台读取剪贴板内容。
6、模型与配置文件保存在应用自己的数据目录中，卸载应用时会一并删除，请及时备份重要文件。
