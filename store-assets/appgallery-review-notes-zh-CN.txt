一、READ_PASTEBOARD（读取剪贴板）—— 权限申请理由
【AGC 填「权限申请理由」栏，限 256 字】
================================================================

本应用是基于开源框架 Qt 与 FreeCAD 构建的三维 CAD，界面由 Qt 自绘，不含 HarmonyOS
系统粘贴控件，无法通过系统控件完成粘贴，因此需要使用剪贴板接口读取用户主动复制的文本。

使用场景：用户把外部复制的文本粘贴进应用内输入框。当前唯一入口是「FreeCAD AI」工作台
设置页的大模型 API Key 与接口地址输入框——这段文本通常有几十个字符，手工输入困难，粘贴
是必要的操作方式。

应用只在用户按下 Ctrl+V 时读取剪贴板，不监听剪贴板变化、不读取剪贴板历史、不在后台读取，
也不上传剪贴板内容。该权限已在本应用的发布 Profile 中声明。

二、READ_PASTEBOARD —— 使用场景说明（详细版）
【AGC 若提供更长的「使用场景说明」栏，或审核追问时回复用】
================================================================

一、为什么必须用剪贴板接口，而不能用系统粘贴控件

本应用的可视界面由 Qt 6 自行绘制（这是跨平台桌面 CAD 的通行做法，FreeCAD 上游、Blender、
KiCad 等均如此），不使用 HarmonyOS 系统 UI 组件。系统粘贴控件依赖系统输入框，本应用没有
系统输入框可用，因此只能直接调用剪贴板接口。华为《受限开放权限》中"基于开源框架开发、
无法使用系统粘贴控件"正是允许申请本权限的场景之一；本应用只分发到 PC 与 2in1 设备，
属于该权限"PC/2in1 设备上的应用均可申请"的最宽松一档。

二、实际使用场景（唯一入口）

FreeCAD AI 工作台 → 设置对话框 → 大模型服务配置：
  · API Key 输入框：粘贴用户从模型服务商控制台复制的密钥；
  · 接口地址（Base URL）输入框：粘贴用户自建服务或代理的地址。

操作方式：用户在应用内点击该输入框使其获得焦点，再按键盘 Ctrl+V。除此之外应用内没有其他
粘贴入口。粘贴内容是用户自己从外部复制、主动带入应用的数据。

三、应用不会做的事

  · 不在启动时读取剪贴板，不在后台读取，不轮询剪贴板变化；
  · 不读取剪贴板历史记录，只取当前一次粘贴动作对应的内容；
  · 不把剪贴板内容上传到任何服务器。API Key 保存在应用自己的数据目录
    （沙箱内 freecad-home/ 下的配置文件），仅用于向用户自己配置的模型服务发起请求。
  · 不请求 WRITE_PASTEBOARD（系统未提供该权限），本应用不写入剪贴板。

四、授权方式

应用启动时会调用一次权限申请接口。按华为规则，PC/2in1 设备上首次申请剪贴板权限不会向
用户弹窗，系统默认授予"允许"，用户可在「设置 > 隐私与安全」中随时关闭。

三、READ_PASTEBOARD —— 场景视频拍摄脚本
【AGC 要求上传权限场景视频。下面按 60 秒左右设计，一镜到底即可，不必剪辑】
================================================================

拍摄要求：真机（HarmonyOS PC / 2in1）屏幕录制，能看清光标位置与实际输入结果；
不需要解说与字幕，画面自证即可；分辨率建议 1920×1080。

分镜（约 60 秒）：

00:00–00:08  桌面，从图标启动本应用。保留一段启动等待（首次启动需解压运行时，可能较慢，
             视频里可以直接跳到界面出现，但不要剪掉应用是自己启动的这一段）。
00:08–00:18  应用主界面。打开菜单「编辑 → 首选项」或工作台下拉框，切换到
             「FreeCAD AI」工作台，让审核看到这是应用内的正常功能入口。
00:18–00:28  在 FreeCAD AI 面板打开设置（Settings），滚到模型服务配置区域，
             先让画面停在"空的 API Key 输入框"上两秒。
00:28–00:36  退出到桌面（或打开一个文本编辑器 / 浏览器地址栏），选中一段文本并按 Ctrl+C
             复制——这一步是为了让"内容来自应用外部"在画面里成立。
00:36–00:48  切回应用，点击 API Key 输入框使其获得焦点，按 Ctrl+V，文字出现在输入框中。
             这一段是关键证据：粘贴前后输入框内容发生变化要看得清。
00:48–00:56  再演示一次反向对照：点击另一个输入框（接口地址），按 Ctrl+V 同样能粘入，
             或者按 Ctrl+C 后到外部文本编辑器里粘贴，说明应用不写剪贴板。
00:56–01:00  停在设置页，收尾。

拍摄注意：
  · 不要用模拟器截图/录屏，必须真机；
  · 先确认设备已授予该权限（PC 上默认授予），否则粘贴会"没反应"；
  · 视频里不要出现真实的 API Key。可以先把要复制的文本改成一串假字符（例如
    sk-demo-not-a-real-key），既保护密钥，也不影响演示效果。

四、INTERNET（网络）—— 权限使用说明
【AGC 填 INTERNET 权限说明栏】
================================================================

本应用申请网络权限用于两项由用户主动触发的功能：

一、FreeCAD AI 工作台（内置第三方开源插件 freecad-ai）
用户在设置中自行填写模型服务地址与 API Key 后，应用通过 HTTPS 向该地址发送请求，用于
根据用户输入生成或修改建模脚本。应用自身不提供大模型服务，不内置任何服务商密钥，也不
收集用户的对话内容。用户不配置、不使用该功能时，不产生任何网络请求。

二、插件管理器（Addon Manager）
用户在「工具 → 插件管理器」中查看、安装 FreeCAD 社区插件时，应用从插件目录拉取列表与
插件包。该功能完全由用户主动打开与点击安装触发，应用不会在启动时或后台自动下载。

除上述两处，应用内没有其他网络访问。应用不上传用户模型文件、不上报使用数据、不含广告
与统计 SDK。

五、内嵌 Python 运行时的说明
【AGC 若以「包内包含源代码文件 / 动态执行代码」为由问询，用这段回复】
================================================================

一、为什么包内有 Python 源码与解释器

本应用是开源三维 CAD 软件 FreeCAD 的 HarmonyOS 原生移植版。FreeCAD 用 C++ 实现几何
内核与界面，但其工作台、后处理与自动化能力大量采用 Python 编写，Python 是本应用的组成
部分与官方扩展方式，而非外部注入的脚本。包内两个压缩载荷（rawfile/python311.zip 约
2.8 MB、rawfile/freecad-runtime.zip 约 59 MB）是随包固定分发的 Python 3.11 解释器与本
应用自带的 Python 模块（Part、Sketcher、Draft、BIM、CAM、FEM 等），不含任何第三方下载的
内容。

二、运行的是什么代码

  1. 随安装包固定分发的 Python 模块（上述两个载荷，发布后不可变）；
  2. 用户自己在本地创建或打开的文件：.FCMacro 宏与 .py 脚本，以及用户在应用内 Python
     控制台输入的语句。这与桌面上任何 Python 环境的行为一致，属于用户对自己设备上文件的
     正常操作；
  3. 用户主动确认后执行的建模脚本：FreeCAD AI 工作台可以由模型服务生成一段建模脚本，
     但默认设置下（auto_execute = 关闭）**不会自动运行**，需要在界面上由用户点击执行；
     执行前应用会自动保存文档并开启撤销事务，执行时有超时保护，可一键撤销；
  4. 用户主动安装的社区插件（见第三部分）。

三、应用不会做的事

  · 不下载可执行文件并运行；
  · 不做应用自更新、不做热更新、不替换包内代码；
  · 不绕过应用市场审核动态加载新功能；
  · 不内置任何远程控制通道。
应用内所有代码执行都发生在设备本地，且都由用户主动发起。本应用为开源软件，全部源代码
可公开审计，随应用提供的许可证文本包含各开源组件（Qt 6、Open CASCADE Technology、
Coin3D、Python、NumPy 等）的许可信息。

六、关于「插件管理器」的边界说明
【可选，供审核追问时使用；若审核明确要求移除，可评估下一版本去掉该入口】
================================================================

插件管理器是 FreeCAD 官方的扩展机制，功能为浏览并安装社区贡献的工作台插件。它的行为：

  · 完全由用户主动打开对话框触发，应用启动时不联网、不自动检查更新；
  · 安装目标是在应用自己的数据目录内，安装后新插件随应用一起启动，不涉及系统级改动；
  · 插件来源为 FreeCAD 官方社区插件目录（公共开源仓库），与第三方应用商店无关；
  · 在此过程中应用不会自动执行插件代码，安装完成后由用户重启应用并在工作台列表中选用。

若审核认为该功能与审核要求存在冲突，我们可以在下一个版本中移除插件管理器入口，只保留
随包分发的工作台。

七、PC / 2in1 桌面特性备注
【AGC 填「备注」栏，供审核实机体验时参考】
================================================================

本应用仅分发至 PC 与 2in1 设备，操作方式沿用桌面版 FreeCAD：

  · 鼠标悬停有预选高亮，单击选中对象，可多选与框选；
  · 键盘快捷键沿用桌面习惯（Ctrl+N/O/S、Ctrl+Z 撤销、Ctrl+V 粘贴、Del 删除等）；
  · 窗口可自由缩放、最大化、最小化，界面按当前像素密度自适应；
  · 首次启动会解压程序运行时，耗时与磁盘占用较大属正常现象，界面上有进度提示；
  · 建议在鼠标环境下体验。触摸屏可完成点按菜单与工具栏操作，但三维视图的旋转/平移、
    面板与列表滚动在触摸下的体验有限，这是桌面 CAD 的固有交互方式，非功能缺陷。
