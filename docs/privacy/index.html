隐私政策

生效日期：2026 年 9 月 15 日 版本 1.0 基于 FreeCAD 1.1.2

English: Privacy Policy

一句话结论：本应用是一款完全在本机运行的三维参数化 CAD 软件，不设账号体系，不收集、不上传、不共享你的个人信息，没有服务器、没有广告、没有统计埋点。除你主动使用联网功能（插件管理器、AI 助手）外，应用不产生任何网络请求。

1开发者与联系方式

开发者：liangxiaohui（个人开发者）
联系方式：项目仓库 Issues 页面 github.com/liang-xiaohui/freecad-on-harmonyos/issues， 或通过 AppGallery 本应用详情页公示的开发者信息与我们联系。

本政策适用于 HarmonyOS PC 与 2in1 设备上的 FreeCAD 端口版本（自 versionName 0.1.0 起的各版本）。

权限授权方式用途使用时机

第三方 SDK 清单

无。本应用除随包分发的开源库（Qt 6、Open CASCADE Technology、Coin3D、Python 3.11、OpenSSL 等）外，不集成任何第三方统计、广告、推送或社交 SDK；上述开源库仅提供图形界面、几何内核、渲染与脚本运行能力，不具备也不执行任何数据采集行为。

应用不含内容推送、广告投放、用户画像或任何形式的数据变现。

5数据存放位置与保留期限

  • 应用产生的全部数据（工程文件、配置、缩略图、缓存、日志）保存在 HarmonyOS 应用沙箱的私有目录中，例如 /data/storage/el2/base/haps/entry/files/freecad-home/，其他应用无法读取。
  • 你在 FreeCAD AI 中填写的 API Key 以明文形式保存在上述私有目录的配置文件（config.json）中，仅本机可读。请不要在共享设备上保存他人的 Key；如需删除，可在插件设置中清除，或直接删除该配置文件。
  • 保留期限由你决定：删除文件即删除数据；卸载应用会一并删除应用私有目录下的全部数据，不保留任何云端副本。请及时备份重要工程文件。
  • 开发者无法访问你设备上的任何数据，也没有留存任何副本。

6共享、转让与公开披露

本应用不收集个人信息，因此不存在向第三方共享、转让或公开披露个人信息的行为。仅当法律法规要求或有权机关依法提出强制性要求时，我们才可能配合——而在本应用的数据结构下，我们没有任何个人信息可供提供。

7你的权利

  • 查阅、更正、删除：应用内可直接编辑或删除你的文件与配置；清除应用数据或卸载应用即彻底删除。
  • 撤回同意：在系统设置中撤销网络或剪贴板权限；停用插件管理器与 AI 功能后，应用不再产生任何网络请求。
  • 由于开发者不持有你的个人信息，无法代你查询或删除数据。如有疑问，可通过第 1 节的联系方式与我们沟通。

8未成年人保护

本应用是通用的三维设计工具，不面向儿童设计，也不会收集任何人的个人信息。若未成年人在监护人指导下使用，请监护人注意：AI 助手功能需要配置第三方服务的 API Key（可能产生第三方服务费用并涉及内容交互），建议由监护人代为配置并监督使用。

9数据安全

  • 本地数据依赖 HarmonyOS 应用沙箱隔离，卸载即清除；
  • 权限申请遵循最小必要，仅 2 项，且均可在系统设置中撤销；
  • 与第三方的通信由应用在你的设备上直接完成，是否使用加密传输取决于你配置的端点；
  • 由于应用与服务端均不留存你的数据，不存在因服务端数据泄露导致你的信息外泄的风险。

10政策的更新

本政策如发生实质性变更，我们会更新版本号与生效日期，并在应用新版本的更新说明及本项目仓库中同步公布；涉及权限范围或数据处理方式的重大变更，会以更显著的方式提示。你继续使用本应用即表示接受更新后的政策。

11与 FreeCAD 官方项目的关系

本应用基于开源项目 FreeCAD 1.1.2 移植，遵循 GNU 宽通用公共许可证第 2.1 版（LGPL-2.1）分发，是非官方的社区移植版本，与 FreeCAD 官方项目及其名称持有人不存在隶属、赞助或授权关系。上游 FreeCAD 的隐私政策见 FreeCAD/FreeCAD/PRIVACY_POLICY.md，其中同样声明不收集、不传输、不共享任何个人数据。
